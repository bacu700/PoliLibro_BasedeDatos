Glosario de Bases de Datos

  • Abstracción de Datos
    Proceso mental e ingenieril para aislar los detalles técnicos del almacenamiento físico y concentrarse en la lógica de negocio.

  • Álgebra Relacional
    Conjunto de operaciones matemáticas y lógicas que toman relaciones como entrada y producen nuevas relaciones como resultado.

  • ALTER (LDD)
    Sentencia del Lenguaje de Definición de Datos utilizada para modificar la estructura de un objeto existente en la base de datos.

  • ANSI/SPARC
    Comité de estandarización que definió la arquitectura de tres niveles de abstracción para los sistemas gestores de bases de datos.

  • Asignación por Defecto (DEFAULT)
    Cláusula que asigna automáticamente un valor predeterminado a una columna si no se envía un dato explícito en la inserción.

  • Atomicidad (ACID / 1FN)
    En transacciones, propiedad de "todo o nada". En normalización, se refiere a que cada celda contenga valores indivisibles.

  • Atributo (Columna)
    Propiedad, cualidad o característica que describe a una entidad dentro de un modelo relacional.

  • Base de Datos Documental
    Motor NoSQL optimizado para almacenar, consultar y gestionar información en forma de documentos estructurados (JSON/BSON).

  • Base de Datos NoSQL
    Sistemas de almacenamiento no relacionales diseñados para esquemas flexibles, alta velocidad y escalabilidad horizontal masiva.

  • Base de Datos Orientada a Columnas
    Motor NoSQL que organiza físicamente los datos en disco de forma contigua por columnas para acelerar consultas analíticas masivas (OLAP).

  • BSON
    Formato de intercambio binario utilizado para almacenar documentos y realizar búsquedas rápidas en bases de datos como MongoDB.

  • Cardinalidad
    Mapeo numérico que expresa cuántos registros de una tabla pueden asociarse con registros de otra tabla (1:1, 1:N, N:M).

  • Clave-Valor (Key-Value)
    El modelo NoSQL más simple, donde los datos se recuperan indexados exclusivamente a través de un identificador único (clave).

  • Consistencia (ACID)
    Propiedad que garantiza que una transacción nunca romperá las reglas de integridad ni corromperá el estado lógico de la base de datos.

  • CONSTRAINT
    Restricción o regla lógica declarada de forma explícita en el servidor para forzar el cumplimiento de la integridad de los datos.

  • CREATE (LDD)
    Sentencia base del Lenguaje de Definición de Datos utilizada para construir físicamente tablas, índices, vistas y esquemas.

  • DELETE (LMD)
    Comando del Lenguaje de Manipulación de Datos utilizado para remover físicamente uno o más renglones de una tabla.

  • Diccionario de Datos
    Repositorio de metadatos que almacena las definiciones lógicas, tipos de datos y restricciones de todos los objetos de la base de datos.

  • Diseño Físico
    Fase de implementación donde el modelo lógico se traduce a scripts de código DDL ejecutables en un motor de bases de datos específico.

  • Dominio
    Conjunto completo de valores atómicos y válidos que un atributo específico tiene permitido adoptar en el sistema.

  • DROP (LDD)
    Sentencia estructural utilizada para eliminar permanentemente un objeto (tabla, vista o índice) junto con todos sus datos del disco.

  • Esquema de Base de Datos
    Representación o mapa lógico y estructural que define la organización completa de las tablas, columnas y relaciones del sistema.

  • Familias de Columnas (Column Families)
    Estructuras lógicas en motores de columnas anchas que agrupan atributos relacionados para ser almacenados juntos físicamente.

  • Funciones de Agregación
    Operadores que procesan un conjunto completo de valores en una columna para devolver un único resultado analítico (SUM, AVG, COUNT).

  • Funciones Escalares
    Operadores SQL que transforman un valor de celda de forma individual fila por fila (ej. convertir texto a mayúsculas o dar formato a fechas).

  • GRANT (LCD)
    Sentencia del Lenguaje de Control de Datos utilizada para conceder privilegios o permisos de seguridad específicos a los usuarios.

  • Inconsistencia de Datos
    Falla operativa donde copias desincronizadas del mismo dato muestran valores diferentes en distintos archivos o departamentos.

  • Independencia de Datos
    Capacidad del enfoque moderno para modificar el almacenamiento físico o el esquema lógico sin necesidad de reprogramar el software de aplicación.

  • INSERT (LMD)
    Sentencia utilizada para capturar e introducir nuevos registros o filas de información dentro de una tabla.

  • Integridad de Entidad
    Regla que prohíbe estrictamente que una Llave Primaria admita valores nulos (NULL) o registros duplicados en la tabla.

  • Integridad Referencial
    Regla que garantiza la coherencia entre tablas, exigiendo que el valor de una Llave Foránea coincida con una Llave Primaria válida existente.

  • JOIN (Reunión)
    Operación lógica que cruza y unifica datos distribuidos en múltiples tablas basándose en una condición de igualdad de llaves (PK/FK).

  • Lenguaje de Control de Datos (LCD / DCL)
    Subconjunto de comandos de SQL encargados de administrar la seguridad y la asignación de privilegios a los usuarios.

  • Lenguaje de Definición de Datos (LDD / DDL)
    Subconjunto de comandos de SQL utilizados para crear, modificar y estructurar físicamente los objetos del servidor.

  • Lenguaje de Manipulación de Datos (LMD / DML)
    Subconjunto de comandos de SQL orientados a gestionar la información interna de las tablas (consultar, insertar, actualizar y borrar).

  • Llave Foránea (Foreign Key - FK)
    Atributo en una tabla secundaria que hace referencia directa a la Llave Primaria de una tabla primaria para establecer una unión lógica.

  • Llave Primaria (Primary Key - PK)
    Atributo o conjunto mínimo de campos que identifica de forma única, inequívoca y obligatoria a cada tupla en una relación.

  • Modelo Conceptual
    Esquema semántico y gráfico de alto nivel (como el Diagrama Entidad-Relación) abstracto e independiente de cualquier software o tecnología.

  • Modelo Entidad-Relación (DER)
    Herramienta estándar de modelado conceptual basada en entidades (rectángulos), atributos (óvalos) y relaciones (rombos).

  • Modelo Lógico
    Etapa de estructuración donde el mapa abstracto se adapta a las reglas de un paradigma específico, como el Modelo Relacional.

  • Modelo Relacional
    Paradigma basado en la teoría matemática de conjuntos donde los datos se organizan formalmente en tablas interconectadas entre sí.

  • Normalización
    Proceso lógico-matemático aplicado a las tablas relacionales para eliminar redundancias y prevenir anomalías de actualización.

  • NOT NULL
    Restricción física que obliga al sistema a exigir un valor obligatorio en una columna, rechazando celdas vacías.

  • Prueba de Estrés (Stress Testing)
    Simulación de miles de consultas concurrentes en el servidor de desarrollo para validar tiempos de respuesta y detectar cuellos de botella.

  • Redundancia de Datos
    Almacenamiento innecesario e idéntico del mismo dato en múltiples carpetas o archivos independientes, característico de los sistemas antiguos.

  • Relación Recursiva (Reflexiva)
    Vínculo especial del negocio donde una entidad se conecta consigo misma a través de una llave foránea interna.

  • REVOKE (LCD)
    Sentencia utilizada para retirar de forma selectiva privilegios o permisos previamente asignados a un usuario de la base de datos.

  • SDLC (Ciclo de Vida de Sistemas)
    Metodología estructurada de ingeniería para guiar un sistema de información desde la planificación hasta su operación.

  • Sharding (Fragmentación Horizontal)
    Estrategia arquitectónica de bases de datos NoSQL para distribuir colecciones de datos a través de múltiples nodos de un clúster.

  • Sistema de Gestión de Bases de Datos (DBMS)
    Software intermediario centralizado que controla de forma directa el almacenamiento, la seguridad y el acceso físico a los datos.

  • Teorema de CAP
    Principio informático que establece que un sistema distribuido solo puede garantizar dos de tres propiedades de forma simultánea: Consistencia, Disponibilidad o Tolerancia a Particiones.

  • Tupla (Registro)
    Fila individual que agrupa datos relacionados correspondientes a una misma entidad única en el modelo relacional.

  • UPDATE (LMD)
    Sentencia utilizada para modificar los valores de atributos específicos en registros ya existentes dentro de la base de datos.

  • Vista (Tabla Virtual)
    Objeto de seguridad basado en una consulta SELECT predefinida que expone datos filtrados de tablas reales sin guardarlos físicamente de nuevo.
