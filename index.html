Diseño de Bases de Datos

La materia de Diseño de Base de Datos tiene como propósito desarrollar en el estudiante las habilidades necesarias para analizar, estructurar y administrar información de manera eficiente dentro de sistemas informáticos. A través de esta asignatura se estudian los principios fundamentales del modelado de datos, la organización de la información y la creación de bases de datos capaces de satisfacer las necesidades de distintos entornos empresariales y tecnológicos.

Durante el curso se abordarán conceptos esenciales como modelos entidad-relación, normalización, diseño lógico y físico de bases de datos, integridad de datos y lenguaje SQL. Estos conocimientos permiten construir sistemas de almacenamiento confiables, seguros y optimizados, facilitando la correcta gestión y consulta de la información.

Asimismo, la materia busca fortalecer el pensamiento analítico y la capacidad de resolución de problemas, ya que el diseño adecuado de una base de datos impacta directamente en el rendimiento y funcionamiento de aplicaciones, plataformas y sistemas de información modernos. De esta manera, el estudiante comprenderá la importancia de las bases de datos como uno de los pilares fundamentales dentro del desarrollo de software y la infraestructura tecnológica actual.

El objetivo de esta actividad es identificar los conocimientos previos de la unidad de aprendizaje, las necesidades, debilidades y fortalezas de los alumnos, para mejorar el aprendizaje.

Recurso digital de apoyo para el aprendizaje de Diseño de bases de datos
Enfocado en el autoestudio y reforzamiento en clase.

La intención de este recurso digital es apoyar a los estudiantes para que adquieran los conocimientos y la habilidad de modelar, organizar y gestionar la información, a través del uso de las diferentes metodologías de diseño y sistemas gestores de bases de datos utilizando un lenguaje de consulta estructurado. Para lograrlo, se basará en la metodología de aprendizaje invertido en el aula.

Intención Educativa
La unidad contribuye al perfil de egreso de la Licenciatura en Ciencias de la Informática con el desarrollo de las habilidades de diseño de modelos pertinentes, implementación y uso de bases de datos, para participar en la solución de problemas de manejo de información en cualquier tipo de organización. Asimismo, fomenta la comunicación, la orientación a resultados, la innovación, la resiliencia, el liderazgo, el trabajo en equipo, con un alto sentido de inclusión, equidad, erradicación de la violencia de género y cultura de la paz, al propiciar ambientes de respeto, diálogo y tolerancia entre los alumnos.

Esta unidad de aprendizaje se relaciona de manera antecedente con Abstracción y uso de datos y Requerimientos de software, de manera lateral con Construcción de software y de manera consecuente con Sistemas Manejadores de Bases de Datos, Programación WEB y Modelos de prueba de software.

Propósito de la Unidad de Aprendizaje
Diseña bases de datos eficientes a partir de su modelo de datos, tecnología adecuada, arquitectura y características.

Propósito de la Unidad de aprendizaje:

Temario de la Unidad de Aprendizaje:

A continuación se presentan las unidades temáticas que estructuran el desarrollo del curso, orientadas al diseño conceptual, lógico y físico de almacenes de información tanto relacionales como no relacionales.

Unidad I. Modelado de bases de datos relacionales y No SQL
Unidad de competencia: Diseña modelos conceptuales a partir de sus elementos, análisis y manejo de la información.

1.1 Elementos
1.1.1 Ambiente de bases de datos e historia del manejo de información
1.1.2 Ambiente de información con Sistemas de archivos y con tecnología de Bases de Datos
1.1.3 Aspectos básicos de Base de Datos Software de Bases de Datos Relacionales y No-SQL
1.1.4 Ambiente y ventajas de los sistemas de información con tecnología de Bases de Datos
1.1.5 Esquemas de la arquitectura de la base de datos relacionales
1.2 El análisis y diseño de bases de datos
1.2.1 Ingeniería de Software
1.2.2 Ciclo de vida de sistemas
1.2.3 Ciclo de vida relacionado al modelado de BD's
1.2.4 Métodos, herramientas, procedimientos y su relación al ciclo de vida de un sistema
1.3 Modelos de Información
1.3.1 Modelo y componentes
1.3.2 Modelos orientados al registro
1.3.3 Modelos orientados al Objeto
1.3.4 Modelos No-SQL
1.4 El modelo conceptual de datos
1.4.1 Recuperación de hechos, información y análisis de requerimientos
1.4.2 Abstracción y representación
1.4.3 Modelo conceptual de datos
1.4.4 Modelo Entidad Relación

Unidad II. Conversión al modelo relacional de bases de datos
Unidad de competencia: Diseña modelos relacionales a partir de su estructura, características y operaciones del ambiente de bases de datos relacionales.

2.1 Modelo Relacional de Bases de Datos
2.1.1 Estructura y características del modelo Relacional de bases de datos
2.1.2 Operaciones que apoyen el modelo relacional
2.1.3 Llave primaria, Llave Foránea e Integridad de bases de datos relacionales
2.1.4 Relaciones n-arias y Relaciones recursivas
2.1.5 Aplicación de los elementos anteriores en Modelo Relacional
2.2 Diseño de BD's relacionales transformando el Modelo conceptual en Modelo Relacional
2.2.1 Proceso de normalización
2.2.2 Conversión de cardinalidad a posición de llaves primarias y foráneas
2.2.3 Aplicación de características del modelo relacional: Tipo de dato, longitud, característica de nulos, integridad de dominio e integridad referencial

Unidad III. Implementación física de la estructura de bases de datos
Unidad de competencia: Crea bases de datos a partir de un modelo relacional, necesidades de manejo de información e instrucciones específicas con el Lenguaje de un Sistema Manejador de Bases de Datos.

3.1 Lenguaje Estructurado de Consulta (SQL)
3.1.1 Antecedentes, características y ventajas del SQL
3.1.2 Estándares de SQL
3.2 Diseño físico de Bases de Datos
3.2.1 Lenguaje de Definición de Datos (LDD) del SQL
3.2.2 Creación de tablas y aplicación de cláusulas NULL, NOT NULL, DEFAULT, PRIMARY KEY, FOREIGN KEY Y CONSTRAINT
3.2.3 Modificación de características de Objetos y eliminación de Objetos
3.3 Seguridad de datos y privilegios de usuarios
3.3.1 Uso de vistas
3.3.2 Lenguaje de Control de Datos (LCD) del SQL
3.3.3 Privilegios aplicables a las tablas
3.4 Manejo de información de las Bases de Datos
3.4.1 Lenguaje de Manipulación de datos (LMD)
3.4.2 Inserción, actualización y eliminación de renglones
3.4.3 Consultas simples y multitabla utilizadas para consultas
3.4.4 Funciones de columnas y funciones escalares

Unidad IV. Introducción a Bases de datos No SQL
Unidad de competencia: Explica modelos no relacionales de bases de datos a partir de la tecnología de bases de datos No SQL.

4.1 Bases de datos No SQL
4.1.1 Bases de datos clave-valor: Características, arquitectura y modelo
4.1.2 Bases de datos documentales: Características, arquitectura y modelo
4.1.3 Bases de datos orientadas a columnas: Características, arquitectura y modelo
4.2 Software y lenguaje para implementar y usar bases de datos No SQL
